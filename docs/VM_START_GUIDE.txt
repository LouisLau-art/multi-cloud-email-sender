邮件系统虚拟机快速操作说明

1）每天开机后如何启动
- 双击 `start.bat`。
- 等待出现以下提示：
  - `App running.`
  - `[Tunnel] URL: https://...trycloudflare.com`
  - `[Tunnel] track_domain auto-updated.`

2）现在已经自动完成的事情
- 自动启动后端（8000 端口）。
- 自动启动前端（5173 端口）。
- 自动启动 cloudflared 临时隧道。
- 自动把新的隧道地址写入系统 `track_domain`。

3）宿主机或虚拟机重启后怎么办
- 仍然只需要双击 `start.bat`。
- 临时隧道域名每次可能变化，这是正常现象。
- 不再需要手动执行：
  - `cloudflared tunnel --url http://localhost:8000`

4）如何停止服务
- 运行：
  - `start.bat -s`
- 该命令会停止后端、前端和隧道进程。

5）注意事项
- 如果要统计打开率/点击率，请在启动后发送“新邮件”。
  旧邮件里已经生成的链接不会自动更新。
- 如果隧道启动失败，请查看日志：
  - `logs/tunnel.log`
- 如果找不到 `cloudflared.exe`，请放到：
  - `%USERPROFILE%\Downloads\cloudflared.exe`
  或把 `cloudflared` 加到系统 PATH。
