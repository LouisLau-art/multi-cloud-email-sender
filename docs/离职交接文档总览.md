## 1. 先看这一页

当前与离职交接最相关的工作，不是继续扩展业务功能，而是把以下四类资产从“个人风险”变成“公司可持续维护”：

1. Cloudflare zone
2. Cloudflare Tunnel
3. Windows 服务器上的 `cloudflared` 配置
4. 应用内 `track_domain`

当前推荐的正式追踪域名是：

```text
https://track.louisliu.fun
```

当前推荐的默认接管路径是：

```text
新公司账号 / 新 Cloudflare zone / 新 tunnel / track.louisliu.fun
```

## 4. 当前主路径

除非有新的管理决策，否则当前主路径统一为：

1. 使用公司账号接管或新建 Cloudflare zone
2. 等 zone `Active`
3. 在公司账号下新建 tunnel
4. 让 `track.louisliu.fun` 指向新的 tunnel
5. 更新 Windows 服务器 `cloudflared`
6. 更新应用 `track_domain`
7. 做真实发信闭环验证
