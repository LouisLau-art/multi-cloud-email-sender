# 交接会议脚本：60 分钟版

> 用途：离职前最后一次技术交接会  
> 目标：让接手同事真正拿到权限、知道主路径、知道未完成项

---

## 0-5 分钟：定目标

这场会先明确三件事：

1. 谁接 Cloudflare
2. 谁接 Windows 服务器
3. 谁对 `track.louisliu.fun` 的上线和验证负责

不要一上来就陷入技术细节。

---

## 5-15 分钟：确认账号归属

现场确认：

- Cloudflare 谁能登录
- 阿里云域名控制台谁能登录
- Windows 服务器谁能登录
- GitHub / Gitee 谁能提交

输出：

- 填写 [账号与权限交接台账模板.md](/root/multi-cloud-email-sender/docs/%E8%B4%A6%E5%8F%B7%E4%B8%8E%E6%9D%83%E9%99%90%E4%BA%A4%E6%8E%A5%E5%8F%B0%E8%B4%A6%E6%A8%A1%E6%9D%BF.md)

---

## 15-25 分钟：统一技术路线

明确统一口径：

- 目标固定域名：`track.louisliu.fun`
- 默认主路径：**新账号 + 新 zone + 新 tunnel**
- 不再把旧 `9ff...` tunnel 当主路径
- 普通同事继续按双击 SOP 使用

输出：

- 接手人能复述这条主路径

---

## 25-40 分钟：现场验证当前真实状态

技术接手同事现场操作：

1. `nslookup -type=ns louisliu.fun`
2. 打开 Cloudflare 看 zone 是否 `Active`
3. 查看是否已有新 tunnel
4. 查看 Windows `cloudflared` 服务状态
5. 查看应用当前 `track_domain`

输出：

- 当前状态清单
- 未完成事项清单

---

## 40-50 分钟：确认下一步负责人

逐项明确：

- 谁负责 zone 激活收尾
- 谁负责新 tunnel 创建
- 谁负责修改 Windows `cloudflared`
- 谁负责更新 `track_domain`
- 谁负责做真实发信验证

输出：

- 每一项都有负责人

---

## 50-60 分钟：确认交付物

最后确认接手人已经拿到：

- 普通同事版文档
- 技术版文档
- Cloudflare 专项手册
- `track_domain` 更新说明
- `cloudflared` 配置模板
- zone 文件

如果这些还只在离职人电脑里，这场会不能算结束。
