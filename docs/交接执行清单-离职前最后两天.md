# 交接执行清单：离职前最后两天

> 适用时间：离职前最后 1-2 天  
> 目标：不是把所有技术细节都做完，而是保证公司同事能真正接住这套系统

---

## 1. 总目标

在离职前，至少做到：

- 文档交出去
- 权限交出去
- 技术同事现场接过一次
- 剩余未完成项清楚

---

## 2. 今天必须完成

### A. 文档交付

- [ ] 把普通同事版交给日常使用同事
- [ ] 把技术同事版交给技术接手人
- [ ] 把 PDF 版也一起发出
- [ ] 把专项手册和模板文件一起打包

### B. 权限确认

- [ ] 确认技术接手人能登录 Cloudflare
- [ ] 确认技术接手人能登录阿里云域名后台
- [ ] 确认技术接手人能登录 Windows 服务器
- [ ] 确认技术接手人能访问代码仓库

### C. 会议安排

- [ ] 约明天一场现场交接
- [ ] 明确谁负责 Cloudflare
- [ ] 明确谁负责 Windows 服务器
- [ ] 明确谁负责域名注册商

---

## 3. 明天必须完成

### A. 现场验证真实状态

- [ ] 跑 `nslookup -type=ns louisliu.fun`
- [ ] 看 Cloudflare zone 是否 `Active`
- [ ] 看是否已有新 tunnel
- [ ] 看 Windows `cloudflared` 服务状态
- [ ] 看当前 `track_domain`

### B. 明确最后路线

- [ ] 确认是否使用新公司账号
- [ ] 确认是否在新账号下新建 tunnel
- [ ] 确认目标追踪域名是 `track.louisliu.fun`

### C. 实际接手

- [ ] 让接手同事自己登录 Cloudflare
- [ ] 让接手同事自己登录阿里云
- [ ] 让接手同事自己登录 Windows 服务器
- [ ] 不是看演示，而是他自己操作一次

---

## 4. 如果来不及完成全部迁移

那也要至少完成以下四件事：

- [ ] 公司同事已经拿到权限
- [ ] 文档已经交出去
- [ ] 主路径已经统一成“新账号 + 新 tunnel + `track.louisliu.fun`”
- [ ] 未完成事项已写成 checklist

---

## 5. 明确不必强求的事情

在离职前，不必强求以下事项已经 100% 完成：

- [ ] 新 zone 全球传播完全结束
- [ ] 新 tunnel 连续运行很久
- [ ] 所有旧资产都彻底清理干净

这些属于迁移收尾，不是交接成立的最低条件。

---

## 6. 最后的口径

如果有人问“离职前必须把这事全做完吗”，标准回答是：

> 不一定要把所有技术细节都完全做完，但必须把账号、权限、文档、主路径和接手责任交清楚，让公司能在你离职后继续独立推进。
