# 邮件推送系统 - 数据准备指南

## 1. 账号授权信息
系统需要连接阿里云接口，请提供具有 **邮件推送(DirectMail) 权限** 的账号密钥：
- **AccessKey ID**: 
- **AccessKey Secret**: 

## 2. 发信配置
请提供在阿里云控制台 **“发信地址”** 页面状态为 **“验证通过”** 的地址：
- **发信地址 (Account Name)**: (例如: news@mail.example.com)
- **发件人昵称 (From Alias)**: (例如: 市场部, 客户关怀组)

## 3. 收件人列表格式
系统支持批量导入联系人，请准备 **CSV 格式** 的文件（Excel 可直接“另存为 CSV”）。

**文件规范：**
1.  **必须包含表头**（第一行）。
2.  必须包含 `email` 列。
3.  推荐包含 `name` 列（用于在邮件标题中显示客户名字，提升点击率）。

**标准示例：**
```csv
email,name
zhangsan@qq.com,张三
lisi@163.com,李四
wangwu@gmail.com,王总
```

## 4. 邮件模板规范
为了实现“千人千面”的个性化发送，请在撰写邮件文案时使用变量。

- **变量格式**: `${name}`
- **适用位置**: 邮件标题、邮件正文

**示例：**
- **标题**: 您好 ${name}，这是为您准备的专属报告
- **正文**: 
  > 亲爱的 ${name}：
  > 
  > 感谢您长期以来的支持...

**提示**：系统会自动处理由于阿里云限制导致的每日额度问题，将大任务自动切分为小批次（如每 15 分钟发送 2000 封），您无需手动分批。
