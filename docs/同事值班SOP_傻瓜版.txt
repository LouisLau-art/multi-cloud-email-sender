【邮件系统每日操作（傻瓜版）】

先记住3个双击文件（都在项目根目录）：
1. 01-启动系统.bat
2. 02-停止系统.bat
3. 03-发信前检查.bat

一、上班后怎么启动（每天都做）
1. 打开 Windows11 宿主机。
2. 打开 VMware，启动 Windows10 虚拟机。
3. 在虚拟机里进入项目目录：
   C:\Users\A\Desktop\multi-cloud-email-sender-main
4. 双击 01-启动系统.bat。
5. 看到这两行就算启动成功：
   - Backend: http://localhost:8000
   - Frontend: http://localhost:5173
   - 以及出现追踪就绪提示（例如 `[Track] Fixed track_domain is healthy.`）
6. 打开浏览器，访问前端地址：
   - 本机用：http://localhost:5173
   - 局域网同事用：看启动弹窗里显示的 http://192.168.x.x:5173


二、发邮件前必须检查（每天都做）
1. 双击 03-发信前检查.bat。
2. 看到“全部通过：可以开始发信”才可以发任务。
3. 如果有失败提示，不要发信，按提示联系管理员。


三、怎么判断“打开/点击统计正常”
1. 发一封测试邮件（给自己邮箱）。
2. 打开邮件一次，再点击正文里一个 http/https 链接。
3. 后端日志里应看到：
   - /api/track/open/... 200
   - /api/track/click/... 302
4. 仪表盘里“打开封数/点击人数”应上涨。


四、下班前怎么关
1. 双击 02-停止系统.bat。
2. 再关虚拟机，再关宿主机。


五、常见问题（先看这个）
1. 打开率突然为 0：
   先双击“03-发信前检查.bat”。
2. 启动脚本直接报错退出（提到 track_domain 不可达）：
   说明追踪链路异常，今天先不要发，联系管理员处理 cloudflared/域名配置。
3. ping-test 不是 200：
   说明追踪域名不可用，先不要发邮件，找管理员处理。
4. 点击率为 0：
   先确认邮件正文里有可点击的 http/https 链接（不是纯文字、不是只写邮箱地址）。


六、非常重要
1. 这台机器如果关机，关机期间的打开/点击可能记不到。
2. 不要随意改 track_domain。
3. 不要把 track_domain 改成 192.168.x.x 这类内网地址。
